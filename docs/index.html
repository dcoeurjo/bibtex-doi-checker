bibtex/pdf-doi-checker

Command-line utilities for checking, completing, and normalizing DOI data in BibTeX files and PDF references.

A digital object identifier (DOI) is a persistent identifier for scholarly publications and other digital objects. This project provides four focused tools for keeping DOI data accurate and useful.

Four tools

Check existing BibTeX metadata, find missing DOI values, clean resolver URLs, and audit DOI references in a PDF.

Installation

Install from a clone with Python 3.9 or newer:

python -m pip install .

For development, install the test dependencies:

python -m pip install -e '.[test]'

BibTeX checker

bibtex-doi-checker reads BibTeX or common BBL files, resolves existing DOI values, and compares the retrieved title and authors with their BibTeX entry.

bibtex-doi-checker -v --threshold 80 references.bib

Options

OptionDescription
-v, --verboseShow each entry and a two-column metadata comparison for mismatches.
--threshold PERCENTMinimum fuzzy title similarity; default: 75.
--csv OUTPUT.csvWrite entry data to CSV.

Final summaries use one stacked progress bar: green for DOI coverage, red for invalid or mismatching records, and gray/yellow for missing or already-present DOI values.

BibTeX fixer

bibtex-doi-fixer looks for high-confidence missing DOI values and writes an updated BibTeX file. It searches both Crossref and arXiv; when both return a candidate, it asks which source to use.

bibtex-doi-fixer -v input.bib references-with-dois.bib

Use --threshold PERCENT to tune the conservative matching threshold (default: 90).

BibTeX cleaner

bibtex-doi-cleaner writes a new BibTeX file with resolver URLs normalized to bare DOI identifiers.

bibtex-doi-cleaner references.bib references-clean.bib

Example

https://doi.org/10.1145/324133.324140 becomes 10.1145/324133.324140.

PDF checker

pdf-doi-checker extracts DOI shortcodes and DOI URLs from a text-based PDF. Invalid values are reported with their one-based page number.

pdf-doi-checker -v article.pdf

Verbose mode prints parsed DOI values and lookup attempts. When a numbered References or Bibliography section is identified, the tool also reports a tentative count of references without a DOI.

CSV output

Every command accepts --csv OUTPUT.csv. BibTeX tools export one row per entry; the PDF tool exports one row per DOI occurrence and leaves BibTeX-specific values blank.

bibtex-doi-checker references.bib --csv report.csv
ColumnContents
bibtex_keyBibTeX citation key, when available.
doiNormalized DOI, or raw DOI text when invalid.
titleBibTeX title, when available.
authorsBibTeX author field, when available.
doi_urlCanonical https://doi.org/... URL for valid DOIs.

Metadata providers

Standard DOI metadata is retrieved from the Crossref REST API. DOI values beginning with 10.48550/arXiv. are resolved through the arXiv API instead.

Network access

Metadata checks require network access. All commands accept --timeout SECONDS to control request limits.
