BIBTEX + CROSSREF

Keep DOI fields
useful.

Three focused commands to check metadata, find missing identifiers, and turn DOI URLs into clean BibTeX fields. Crossref handles standard DOIs; arXiv handles arXiv DOI metadata.

View on GitHub Explore commands ↓

A SIMPLE WORKFLOW

  1. 01 Check your bibliography
  2. 02 Fill confident gaps
  3. 03 Clean the final file

01

Check

Compare each DOI against Crossref title and author metadata. Minor formatting differences are tolerated; likely mistakes stand out. The summary counts all entries, DOI fields, and valid DOI values. Add -v for colored two-column mismatch details and --threshold PERCENT to tune title matching.

bibtex-doi-checker -v --threshold 80 references.bib

02

Fix

Search Crossref and arXiv for entries without a DOI, then add only a clear, high-confidence match to a new BibTeX file. When both sources match, choose the DOI interactively. Add -v for color diagnostics and tune matching with --threshold.

bibtex-doi-fixer -v --threshold 92 input.bib output.bib

03

Clean

Strip resolver hosts from DOI fields and keep the bare identifier your bibliography needs.

bibtex-doi-cleaner input.bib output.bib

04

Scan PDFs

Validate DOI shortcodes and resolver URLs in a text-based PDF. Invalid references are reported with their page number. Add -v to see parsed and tested DOI values.

pdf-doi-checker -v article.pdf

GET STARTED

Install, then run.

python -m pip install .

Requires Python 3.9 or newer and an internet connection for Crossref or arXiv lookups. Each command accepts --timeout SECONDS.
