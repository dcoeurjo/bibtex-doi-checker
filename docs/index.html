RESEARCH METADATA UTILITIES

Reliable identifiers
for research.

Four command-line tools for checking, completing, cleaning, and auditing DOI data in BibTeX files and PDF references.

Metadata is resolved through Crossref and, for arXiv DOIs, the arXiv API.

Explore the tools ↓

AT A GLANCE

Metadata quality,
without the manual audit.

Use the suite to compare DOI metadata with your bibliography, find high-confidence missing identifiers, standardize DOI fields, and review DOI references in a paper before publication.

COMMAND REFERENCE

Four focused tools

01

Check BibTeX

Compare each DOI against title and author metadata, with configurable fuzzy matching and an audit summary.

bibtex-doi-checker -v references.bib

02

Fix missing DOI

Search Crossref and arXiv, then add only high-confidence DOI matches to a new BibTeX file.

bibtex-doi-fixer input.bib output.bib

03

Clean DOI fields

Remove resolver hosts and keep only bare DOI identifiers while preserving the rest of the bibliography.

bibtex-doi-cleaner input.bib output.bib

04

Audit PDF references

Validate DOI shortcodes and URLs in text-based PDFs, reporting invalid references with their page number.

pdf-doi-checker -v article.pdf

Structured output. Every command accepts --csv OUTPUT.csv for DOI reporting data.

METHOD

Conservative by design.

Matching normalizes punctuation, whitespace, Unicode, and author surnames before comparing records. The fixer requires a high-confidence title and author match; if both Crossref and arXiv match, you choose the preferred source.

Crossref
Standard DOI metadata and discovery
arXiv
Metadata for 10.48550/arXiv.* DOI values
PDF pages
Page-aware DOI validation and reference estimates

NORMALIZATION EXAMPLE

A DOI is an identifier,
not a web address.

INPUTdoi = {https://doi.org/10.1145/324133.324140}

OUTPUTdoi = {10.1145/324133.324140}

GET STARTED

Install and inspect your references.

python -m pip install .

Requires Python 3.9 or newer. Network access is required for Crossref and arXiv metadata lookups; use --timeout SECONDS to adjust request limits.
